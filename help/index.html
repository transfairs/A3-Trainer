Willkommen zum A3-Trainer

Ein Trainer (Editor) für Anstoss 3 in der Version 1.10, gebaut auf demselben Grundgerüst wie der A2G-Trainer. Noch ein Proof of Concept: Spieler, Verein und Manager.

So geht's los
  1. Richten Sie Anstoss 3 einmalig so ein, dass es unter Windows 10/11 läuft, siehe Spiel einrichten.
  2. Starten Sie Anstoss 3 und laden Sie einen Spielstand (Karriere).
  3. Starten Sie den A3-Trainer. Die Reihenfolge spielt keine Rolle, der Trainer erkennt das laufende Spiel automatisch und zeigt Ihren Kader.
  4. Wählen Sie links einen Spieler, ändern Sie die Werte und klicken Sie auf Speichern.
  5. Speichern Sie anschließend im Spiel, damit die Änderungen im Spielstand landen.
Automatische Verbindung Der Trainer verbindet sich von selbst mit dem Spiel, egal ob er vor oder nach Anstoss 3 gestartet wird. Startet das Spiel neu oder laden Sie einen anderen Spielstand, aktualisiert er sich automatisch. Im Hauptmenü des Spiels wartet er, bis eine Karriere geladen ist.

Anstoss 3 unter Windows 10/11

Was der Trainer voraussetzt und wie das Spiel auf aktuellen Windows-Versionen startet.

Benötigte Version

Der Trainer unterstützt Anstoss 3 Version 1.10 mit der ungeschützten anstoss3.exe (4.980.803 Bytes). Nur in dieser EXE liegen alle Spieldaten an festen Adressen. Die mit einem Kopierschutz versehenen EXEs (1.0 und die geschützte 1.10) erkennt der Trainer und meldet sie als nicht unterstützt.

3D-Einstellungen: gl.cfg

Ohne die Datei gl.cfg im Spielordner beendet sich Anstoss 3 direkt nach dem Start ohne Meldung. Normalerweise legt sie das 3D-Setup SGLSetup.exe an. Läuft das nicht, legen Sie sie selbst an, zum Beispiel für Direct3D im Fenster:

DLL = d3d_dll.dll
ColorDepth = 16
FullScreen = FALSE

BEGIN D3D
forcewindow = TRUE
TextureCacheSize = 8000000
Driver = ""
MipMapMode = 1
TexelCenter = 0
END
Kompatibilitätsmodus

Bleibt das Spielfenster weiß, stellen Sie für anstoss3.exe unter Eigenschaften → Kompatibilität die Option „Mit 16-Bit-Farbe ausführen“ ein.

Spieler

Erreichbar über das Menü Spieler. Links steht die Spielerliste (verletzte Spieler in Rot), rechts die Details des gewählten Spielers in vier Registerkarten.

Zwei Wege zur Spielerliste
Eigener Kader
Alle Spieler Ihres Vereins. Menü: Spieler → Eigener Kader.
Nächster Gegner
Der Kader des Vereins, den das Spiel als nächsten Gegner geladen hat. Menü: Spieler → Nächster Gegner.
Speichern

Speichern schreibt nur die Werte, die Sie geändert haben. Neu laden liest den Kader neu aus dem Spiel, zum Beispiel nach einem Spieltag. Damit die Änderungen im Spielstand landen, speichern Sie anschließend im Spiel.

Spielerinfo im Spiel vorher schließen Ist im Spiel die Spielerinfo des Spielers geöffnet, schreibt sie beim Schließen ihre eigene Kopie zurück und überschreibt damit die Änderung aus dem Trainer. Schließen Sie die Spielerinfo, bevor Sie im Trainer speichern.

Fehlerbehebung / FAQ

Häufige Fragen, bekannte Grenzen und die Logdatei.

Der Trainer findet Anstoss 3 nicht

Das Spiel muss laufen und eine Karriere geladen sein; im Hauptmenü wartet der Trainer. Meldet er „nicht unterstützt“, läuft eine andere EXE als die ungeschützte Version 1.10, siehe Spiel einrichten.

Meine Änderung ist wieder weg

War im Spiel gerade die Spielerinfo dieses Spielers geöffnet, hat sie beim Schließen ihre eigene Kopie zurückgeschrieben. Schließen Sie die Spielerinfo und speichern Sie im Trainer noch einmal. Damit die Änderung den nächsten Neustart übersteht, speichern Sie im Spiel.

Cheat-Engine-Tabelle

Dem Download liegt A3-Trainer.ct für Cheat Engine bei. Sie enthält den Manager, das Vermögen am Saisonbeginn und das Basisjahr als feste Einträge. Das Skript Kader (eigener Verein und nächster Gegner) liest beim Aktivieren beide Kader ein und legt für jeden Spieler dieselben Felder an wie der Trainer: Positionen, Talent und starker Fuß als Auswahl, Fähigkeiten, Eigenschaften und Charakter als einzelne Schalter.

Nach einem Spieltag oder wenn Sie einen anderen Spielstand laden, das Skript aus- und wieder einschalten.

Bekannte Grenzen (Proof of Concept)
  • Motivation berechnet das Spiel selbst, der Trainer zeigt sie nur an.
  • Bei Torhütern zeigt das Spiel eine niedrigere Kondition an als gespeichert.
  • Manager und Vereinsvermögen gelten nur für Spieler 1.
  • Sperren und Vereine anderer Länder als Deutschland sind noch nicht geprüft.
Logdatei

Der Trainer schreibt nach %LocalAppData%\A3-Trainer\trainer.log. Hängen Sie die Datei bitte an, wenn Sie einen Fehler melden. Ausführlichere Einträge gibt es, wenn vor dem Start die Umgebungsvariable A3TRAINER_DEBUG=1 gesetzt ist.

Über den A3-Trainer

Projekt

Der A3-Trainer ist ein Trainer (Editor) für Anstoss 3, der direkt im Arbeitsspeicher des laufenden Spiels liest und schreibt. Er teilt sich das Grundgerüst mit dem A2G-Trainer. Quellcode und Downloads: github.com/transfairs/A3-Trainer
